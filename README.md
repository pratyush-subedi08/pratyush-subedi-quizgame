# Quiz Game using C++ and Qt

A simple desktop Quiz Game developed using **C++** and the **Qt Framework** as a second-semester Object-Oriented Programming project.

## Features

- Graphical User Interface (Qt Widgets)
- Multiple-choice questions
- Score tracking
- Questions loaded from a text file
- Object-Oriented Programming concepts
- Easy to modify and extend

## Technologies Used

- C++
- Qt 6
- Qt Creator
- CMake

## Project Structure

```
quizgame/
│── main.cpp
│── mainwindow.cpp
│── mainwindow.h
│── mainwindow.ui
│── question.cpp
│── question.h
│── questions.txt
│── CMakeLists.txt
```

## How to Run

### Option 1: Open in Qt Creator

1. Clone the repository:

```bash
git clone https://github.com/pratyush-subedi08/pratyush-subedi-quizgame.git
```

2. Open the project in **Qt Creator**.

3. Open the `CMakeLists.txt` file.

4. Configure the project using your installed Qt Kit.

5. Build and Run the project.

> **Note:** Ensure that `questions.txt` is placed in the executable's working directory so the quiz can load the questions correctly.
